# Contributing

Contributions are welcome: bug fixes, features, docs, translations and design.

1. Open an issue first for anything big so we can agree on the approach.
2. Fork, create a branch, and keep each pull request focused.
3. Run `go mod tidy && go vet ./... && go build ./...` before pushing.
4. Keep the project lightweight: Go standard library first, few dependencies, no front-end build step.

Security problems: please open a private security advisory on GitHub instead of a public issue.

By contributing you agree your work is released under the MIT license.
